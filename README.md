# Apito Final

Simulador de árbitro de futebol para celular. Você apita partidas, dá cartões, marca pênaltis, revisa lances no VAR e sobe na carreira: Série D → Série C → Série B → Série A → Libertadores → Champions League → final da Copa do Mundo.

## Como jogar

- A partida passa sozinha (cerca de 4 minutos). Quando um jogador cair, decida rápido: **toque em APITAR** se foi falta, ou deixe o jogo seguir.
- Depois de apitar, escolha o que marcou (falta, pênalti, simulação ou lance normal) e o cartão.
- Nos gols, decida se vale ou se foi impedimento ou toque de mão.
- Cada decisão certa dá moedas. Nota 7 ou mais conta para subir de liga.
- Nas ligas com VAR (Série A em diante), o VAR pode te chamar ao monitor quando você erra um lance importante.

## Loja

Com as moedas você compra replay, câmera lenta, ângulo aproximado, câmera tática (mostra contato e toque na bola), linhas de impedimento, bandeirinha atento, preparo físico (câmera mais perto), cabine do VAR, equipe de VAR experiente e itens visuais.
